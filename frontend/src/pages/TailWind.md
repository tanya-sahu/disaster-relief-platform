# 🎨 Tailwind Classes Explained (Text Gradient)

### tracking-tight
- Letters ke beech spacing thodi kam karta hai (tight text look)

---

### bg-gradient-to-r
- Gradient background left → right direction me banata hai

---

### from-white
- Gradient ka starting color white hota hai

---

### to-slate-400
- Gradient ka ending color light grey (slate-400) hota hai

---

### bg-clip-text
- Background ko sirf text ke andar clip karta hai  
- Gradient text ke andar fill hota hai

---

### text-transparent
- Text ka actual color transparent kar deta hai  
- Taaki gradient background visible ho sake

---

## 🔥 Final Effect
- Stylish gradient text (white → grey)
- Modern hero section headings me use hota hai

# 🎨 Tailwind Class Explained

### space-y-4
- Vertical spacing between child elements (top to bottom)
- Har child element ke beech ~16px gap add karta hai
- Sirf vertical direction me work karta hai (Y-axis)

## 🔥 Use case
- Form fields ke beech spacing
- Buttons / inputs ko clean vertical layout dena
- Stack layout me consistent gap maintain karna
